# 压力传感器接口与稳定判定参考

> 对应 `pressure_sensor.h` / `pressure_sensor.c`，说明桩接口设计与真实硬件对接方法。

## 1. 设计目标

在 LCD 打印过程中，压力传感器用于判断：

1. **液面接触**：平台压入树脂后压力上升并稳定
2. **剥离完成**：抬升后吸力释放，压力下降并稳定
3. **回位完成**：树脂回流后液面压力恢复稳定
4. **异常保护**：压力突增（撞击 FEP、堵塞）时触发 ERROR

状态机中所有 `WAIT_*_STABLE` 状态均调用 `PressureSensor_ReadAndUpdate()`。

## 2. 稳定判定算法

```c
typedef struct {
    float stable_threshold;   /* 相邻采样最大波动 */
    float sample_interval_ms; /* 采样周期 */
    int   stable_count_req;   /* 连续达标次数 */
} PressureStableCfg_t;
```

逻辑：
1. 每次读取当前压力 `value`
2. 计算与上次采样差值 `|value - last_value|`
3. 若差值 ≤ `stable_threshold`，`stable_count++`；否则清零
4. 当 `stable_count >= stable_count_req` 时，`is_stable = true`

这是一种简单有效的 **滑动窗口式稳态检测**，类似 PLC 中的「连续 N 次在容差内」。

### 推荐参数起点

| 场景 | stable_threshold | stable_count_req | 采样间隔 |
|------|------------------|------------------|----------|
| 接触检测 | 1–5 (归一化) | 5–10 | 10–20 ms |
| 剥离完成 | 2–8 | 8–15 | 20 ms |
| 基线标定 | 0.5–2 | 10–20 | 10 ms |

需根据传感器量程和机械结构标定。

## 3. 硬件对接占位

将 `pressure_sensor.c` 中的桩替换为真实读取：

```c
/* 示例：ADC 单通道 */
float PressureSensor_ReadRaw(void)
{
    uint16_t adc = HAL_ADC_GetValue(&hadc1);
    return (float)adc * 3.3f / 4096.0f;  /* 电压 */
}

/* 示例：I2C 数字传感器 */
float PressureSensor_ReadRaw(void)
{
    uint8_t buf[3];
    HAL_I2C_Mem_Read(&hi2c1, 0x48 << 1, 0x00, 1, buf, 3, 100);
    return (float)((buf[0] << 8) | buf[1]);
}
```

建议在 `PressureSensor_Init()` 中做零点校准（空载采样取平均作为 `baseline`）。

## 4. 与兄弟项目 PID 的关联

同目录上一阶段项目 `1-1PID_Initial` 中的 PID 算法可用于：

- 对压力读数做 **低通滤波**（减少噪声导致的 stable_count 反复清零）
- 闭环调节 Z 轴下压速度，使接触力保持在目标值（恒压接触）

```
压力设定值 → PID → Z 轴进给速度修正
```

这比纯「等待稳定」更进阶，适合柔性材料或精密薄壁件。
