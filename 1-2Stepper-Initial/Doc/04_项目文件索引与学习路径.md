# 项目相关文件索引与学习路径

> 本仓库及周边 C 学习项目的文件导航，便于快速定位可借鉴的代码。

## 1. 本仓库（1-2Stepper-Initial）

| 文件 | 类型 | 说明 |
|------|------|------|
| `main.c` | 入口 | 状态机仿真主程序，含压力曲线注入 |
| `lcd_motion_fsm.h/c` | 核心 | LCD 打印 Z 轴状态机，含压力稳定门控 |
| `gcode_z.h/c` | 驱动层 | G-code Z 轴指令解析与运动仿真 |
| `pressure_sensor.h/c` | 传感层 | 压力读取桩 + 稳定判定算法 |
| `Doc/` | 文档 | 参考文档与可行性分析 |

### 建议阅读顺序

1. `Doc/01_LCD_Z轴运动流程参考.md` — 理解业务流程
2. `lcd_motion_fsm.h` — 看状态枚举
3. `lcd_motion_fsm.c` — 看状态迁移与压力门控
4. `main.c` — 跑仿真验证
5. `pressure_sensor.c` — 理解稳定判定
6. `gcode_z.c` — 理解 G-code 封装

## 3. 业界优质开源参考（外部）

以下项目未包含在本仓库，但强烈建议对照学习：

### Marlin Firmware
- 仓库：https://github.com/MarlinFirmware/Marlin
- 重点文件：`Marlin/src/gcode/motion/G0_G1.cpp`、`module/planner.cpp`
- 价值：工业级 G-code 解析与运动规划

### Klipper
- 仓库：https://github.com/Klipper3D/klipper
- 重点：Python 侧 G-code 宏 + 步进时钟精确控制
- 价值：理解「主机规划 + MCU 执行」架构

### Grbl
- 仓库：https://github.com/grbl/grbl
- 价值：精简的状态机 + 步进中断，适合学习底层逻辑

### Photon / Elegoo 社区固件
- 搜索关键词：`Photon Mono firmware`、`MSLA peel gcode`
- 价值：LCD 打印机真实剥离参数与 G-code 格式

## 4. 编译与运行

```bash
cd e:\Codes\C\1-2Stepper-Initial
gcc main.c pressure_sensor.c gcode_z.c lcd_motion_fsm.c -o lcd_fsm -lm
.\lcd_fsm
```

预期输出：状态逐步从 INIT → ... → IDLE，打印每层曝光/剥离/回位日志。
