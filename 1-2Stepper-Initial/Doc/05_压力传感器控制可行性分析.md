## 1. 背景：LCD 打印 Z 轴控制的痛点

### 1.1 现行主流方法

当前绝大多数 LCD 打印机（Elegoo、Anycubic、Creality 等）采用 **开环时间/位移控制**：

```
切片软件设定：剥离高度 6 mm、速度 60 mm/min、回位后等待 1.5 s
    ↓
固件按 G-code 执行，不感知实际力学状态
```

| 方法 | 优点 | 缺点 |
|------|------|------|
| 固定行程剥离 | 简单可靠 | 大截面件拉坏、小截面件浪费时间 |
| 固定延时等待 | 实现零成本 | 无法区分树脂粘度差异 |
| 电流检测（TMC StallGuard） | 无额外传感器 | 对缓慢变化的剥离力不敏感 |
| 光学液面检测 | 液位精度高 | 不直接反映接触/剥离力 |
| **压力/力传感** | 直接反映力学状态 | 需额外硬件与标定 |

### 1.2 为什么「压力」是关键量

LCD 打印的成败高度依赖 **界面力学**：

- **接触阶段**：平台压入树脂液面，压力上升 → 可判断「是否接触到液面」「接触是否过重」
- **剥离阶段**：FEP 膜与固化层之间的吸力导致压力峰值 → 可判断「是否完成剥离」
- **回位阶段**：树脂回流、液面恢复 → 压力稳定后才曝光，可减少缺层和气泡

这些本质上都是 **力学稳态问题**，压力传感器是最直接的观测量之一。

## 2. 技术可行性分析

### 2.1 传感器选型

| 类型 | 原理 | 适用位置 | 成本 | 备注 |
|------|------|----------|------|------|
| 应变片/称重传感器 | 形变→电阻 | 平台底部、机架 | 中 | 工业成熟，需机械安装 |
| 压阻式 MEMS | 膜片形变 | 液槽底部、平台背板 | 低 | 体积小，适合改装 |
| 气压传感器（封闭腔） | 树脂液面上方密闭空气压力变化 | 树脂槽密封盖 | 低 | 间接测量，需结构设计 |
| 电机电流间接推断 | 步进/TMC 驱动电流 | 无需额外件 | 零 | 精度与延迟较差 |

**推荐**：入门研究用 MEMS 压阻传感器或小型称重模块（如 HX711 + 应变片），量程 0–5 kg 足够。

### 2.2 信号处理

原始压力信号存在噪声与漂移，需：

1. **硬件滤波**：RC 低通 + ADC 过采样
2. **软件滤波**：滑动平均、一阶低通、中值滤波
3. **稳定判定**：连续 N 次在容差内（本项目 `pressure_sensor.c` 已实现）
4. **可选进阶**：PID 恒压控制（可复用 `1-1PID_Initial` 项目）

```
采样频率建议：50–100 Hz（步进控制 1–10 kHz，压力环远低于此）
稳定判定窗口：100–300 ms（本项目约 8×20 ms = 160 ms）
```

### 2.3 与 G-code 状态机的集成

本项目的集成模式：

```
运动指令发出 → 等待 GcodeZ_IsIdle() → 轮询压力稳定 → 才允许下一状态
```

这与 Marlin 的 `M400`（等待运动完成）逻辑类似，只是把「等待完成」扩展为「等待运动完成 + 压力稳定」。

**可行性结论**：在 STM32 / ESP32 等级 MCU 上，额外开销可忽略（<1% CPU）。

### 2.4 主要工程挑战

| 挑战 | 严重程度 | 应对 |
|------|----------|------|
| 传感器安装与密封 | 中 | 结构设计阶段预留 |
| 树脂污染/温度漂移 | 中 | 定期校准 baseline |
| 不同树脂粘度 | 低 | 自适应阈值或学习 |
| 剥离力过大损坏传感器 | 高 | 机械限位 + 过载保护（本项目 `PRESSURE_OVERLOAD_DELTA`） |
| 误判导致死等 | 中 | 超时兜底（本项目 8 s 超时进 ERROR） |

### 3.2 互补而非替代

压力传感 **不应完全取代** G-code 行程控制，最佳实践是 **分层协作**：

```
G-code 负责：剥离高度、速度、层厚的「宏观轨迹」
压力传感负责：每个阶段的「微观完成判据」
超时/限位负责：「安全兜底」
```

这类似数控机床中「位置环 + 力控环」的混合策略（力控磨削、力控装配在工业中已是标准配置）。

### 3.3 与 FDM 力控的类比

FDM 领域中：
- Prusa 等的 **压力提前（Pressure Advance）** 是挤出机 **流量** 控制
- 刀具力控 CNC 用测力计监测切削力

LCD 领域的压力门控是同一思想在 **Z 轴剥离力学** 上的自然延伸，理论根基扎实。

## 4. 应用价值论述

### 4.1 直接收益

1. **首层粘附优化**  
   接触压力稳定后再曝光，避免「未压到液面就曝光」导致的首层缺失。

2. **减少剥离拉坏**  
   检测到压力已释放（吸力消失）即可提前结束等待或进入回位，不必盲目等满固定延时。

3. **树脂自适应**  
   高粘度树脂压力下降慢 → 自动多等；低粘度快 → 自动缩短周期，提高打印效率。

4. **在线质量监测**  
   压力曲线异常（尖峰、漂移）可实时告警，比打印完成后才发现缺层更有价值。

5. **研发调试利器**  
   记录每层压力曲线，可量化比较不同剥离参数、不同 FEP 老化程度的影响。

### 4.2 潜在应用场景

| 场景 | 价值 |
|------|------|
| 薄壁/精细件 | 防止剥离力峰值拉断 |
| 大平面件 | 避免过度剥离浪费时间 |
| 柔性/弹性树脂 | 力控比固定行程更安全 |
| 工业产线 | 过程能力（Cp/Cpk）监测 |
| 科研材料开发 | 力学数据与曝光参数关联分析 |

### 4.3 局限与不宜夸大的地方

- **不能替代切片参数优化**：压力门控是执行层增强，糟糕的剥离高度仍会失败
- **消费级性价比**：对普通用户，调切片比装传感器更经济
- **标定负担**：每台机器、每种树脂可能需要重新标定阈值
- **结构侵入性**：改装需动机械，非即插即用

## 5. 实施路线图建议

### 阶段一：门控型（本项目已实现）

- 压力稳定 → 状态迁移
- 固定 G-code 行程不变
- 实现成本低，风险小

### 阶段二：监测型

- 记录每层压力曲线到 SD 卡 / 串口
- 不干预运动，仅用于分析和告警

### 阶段三：闭环型

- PID 控制接触速度，维持目标压力
- 自适应剥离：压力降至阈值即停止抬升（替代固定 6 mm）

### 阶段四：智能化

- 树脂库 + 压力曲线模板匹配
- 与切片软件联动，自动推荐剥离参数

## 6. 结论

**使用压力传感器稳定读数作为 Z 轴电机控制的状态迁移条件，在技术上完全可行，在工程上具备中等复杂度，在应用上尤其对薄壁件、高价值件、材料研发场景具有显著价值。**

与现行开环 G-code 方案并非对立，而是 **在其之上增加一层力学感知的安全网与优化器**。本项目的 `lcd_motion_fsm.c` 即采用了工业控制中常见的模式：

> **顺序控制（状态机）+ 条件联锁（压力稳定）+ 超时保护（ERROR）**

这是可落地、可渐进扩展的合理架构。若你后续有具体硬件（STM32 + HX711 等），可在 `pressure_sensor.c` 中替换桩函数，状态机逻辑无需大改。
